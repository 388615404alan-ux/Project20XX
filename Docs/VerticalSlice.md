# 垂直切片：避难所原型

## 当前目标

先完成一个可编译、可进入、可操作的第一人称避难所灰盒，验证 UE 5.8.2 工具链和核心交互代码。它不是最终美术，而是商业级生产流程的第一个技术验收点。

## 第一阶段验收

- 第一人称 WASD 移动、鼠标观察与跳跃。
- 准星方向射线交互，按 E 操作目标。
- 可开关的防爆门。
- 三份可搜刮物资和最小库存计数。
- 程序生成的封闭避难所灰盒。
- Project20XXEditor Win64 Development 编译成功。

## 后续顺序

1. 在编辑器中创建项目级测试关卡，替换引擎模板地图依赖。
2. 增加照明、通风设备与辐射/空气质量状态。
3. 把物资、门和设备改为数据驱动交互对象。
4. 接入 Wwise 事件与 RTPC，音频资产由用户制作。
5. 进行第一次可执行文件打包和帧率/显存基准测试。

## 操作

- `W/A/S/D`：移动
- 鼠标：观察
- `Space`：跳跃
- `E`：拾取物资或开关防爆门
