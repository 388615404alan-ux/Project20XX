# 项目起点

## 用户已确定

题材为 20xx 年全球核战争背景下的生存游戏。目标为大型项目、商业级质量。用户具有游戏音频设计专业背景，希望由助手协助承担程序与视觉制作，从零开始建立项目。

用户主要使用 REAPER，熟练使用 Wwise。音效由用户亲自制作，不使用 AI 生成音效；具体音频设计与分工留待后续讨论。助手可协助游戏侧的音频技术接入，具体实施安排待讨论。

当前电脑已确认为主力开发机，配置与磁盘空间见 [主力开发机](Hardware.md)。

## 待讨论的制作分工

建议用户主导音频、创意方向、体验反馈与最终验收；助手负责推进程序、环境搭建、资产制作和整合、技术验证及项目文档。具体能力和必要的外部支持通过实际产出评估。

## 尚未确认的事项

- 正式名称、第一或第三人称、视觉风格。
- 单人或多人、发布平台、地图规模与目标内容时长。
- 预算、周期、目标运行硬件和性能标准。
- 引擎及 Blender 版本、Wwise 与其 UE 集成版本、主力开发机的 SSD 空间安排。
- 资产来源、远端版本库与独立备份位置。

## 可供讨论的首次验证

制作一个可以游玩的避难所场景，验证角色移动、门与物品交互、环境资产导入、音频事件与参数联动，以及打包运行。后续再引入核袭击事件和外出探索。

这是助手建议，尚不代表用户已经批准玩法或范围。
